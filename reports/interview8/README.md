# ارائه ساده هشت‌اسلایدی برای مصاحبه

این ارائه مخصوص مطالعه اصلی حل مستقیم است و شامل PINN نیست. متن اسلایدها انگلیسی و یادداشت‌های کوتاه توضیح فارسی هستند.

- فایل اصلی: [PowerPoint](interview_8_slides.pptx)
- نسخه نمایش: [PDF هشت‌صفحه‌ای](interview_8_slides.pdf)
- یادداشت‌های ساده: [PDF فارسی](notes_fa.pdf) و [متن فارسی](notes_fa.md)

یادداشت هر اسلاید داخل بخش Speaker Notes خود پاورپوینت هم درج شده است. متن‌ها و کادرهای پاورپوینت قابل‌ویرایش‌اند؛ نمودارها به‌صورت تصویر درج شده‌اند و نسخه PDF برداری آن‌ها نیز در پوشه figures موجود است.

| اسلاید | موضوع |
|---|---|
| شماره ۱ | تعریف مسئله، شبکه، هد مرزی و خروجی هدف |
| شماره ۲ | پارامترهای تصادفی و مراحل حل مستقیم |
| شماره ۳ | چهار بررسی فیزیکی روی ۱۰۰۰ شبکه |
| شماره ۴ | آزمون‌های تحلیلی و ناوردایی؛ ۳۹ بررسی ثبت‌شده |
| شماره ۵ | اثر دلتا و سیگما بر میانگین رسانایی |
| شماره ۶ | توزیع خروجی، احتمال صفر، میانگین، میانه و صدک ۹۵ |
| شماره ۷ | روش Sobol/Jansen و تفسیر First-order و Total-order |
| شماره ۸ | چهار نکته Discussion: دو یافته، محدودیت‌ها و توسعه‌های واقعی |

داده‌ها از نتایج واقعی ذخیره‌شده در results و reports/verification خوانده شده‌اند. نمونه نمایشی شبکه در اسلاید اول ۱۱×۱۱ است تا واضح دیده شود؛ اندازه مطالعه اصلی ۲۵×۲۵ است. بررسی‌های عددی، اعتبار پیش‌بینی سنگ واقعی را اثبات نمی‌کنند.

برای بازسازی از ریشه مخزن:

```bash
PYTHONPATH=src OPENBLAS_NUM_THREADS=1 python scripts/build_interview8.py
```
