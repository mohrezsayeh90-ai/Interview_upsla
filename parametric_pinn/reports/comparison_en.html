SEPARATE PARAMETRIC PINN STUDY · 04 NOVEMBER 2026

Train once, reuse across random networks

Parametric graph PINN versus the verified sparse solver. A neural operator receives the full random conductance field and physical parameters, predicts hydraulic head, and estimates effective conductance. Trained weights are reused without a new sparse solve or per-input weight fitting. Every forward evaluation still performs K fixed iterative updates of head.

On 9,000 independent held-out scenario cases (4,518 with positive flow), the K=2048 model has mean absolute relative conductance error 0.0200%, 95th-percentile error 0.0393%, and maximum error 4.7386%. The zero-flow decision is exact graph preprocessing, not a learned classifier.

Practical conclusion. The reusable model works accurately for most in-domain conductance predictions, but errors are not uniformly small. It is an unrolled learned iterative architecture with explicit graph preprocessing, not a closed-form or a single dense-MLP evaluation. The fastest measured PINN setting is 4.35× the sparse G-only latency; no positive break-even is observed. The sparse method remains the preferred precision reference for this inexpensive 25×25 problem.

Why physical scalars alone are insufficient

Two networks with identical δ,p,σ can have different topology and conductance fields, including one spanning and one disconnected. In 1000 test cases with identical δ=0, p=0.5 and σ=1, standard deviation of G was 0.02097; even the best empirical constant predictor had RMSE 0.02096. The model therefore takes the full field, or a seed identifying it. With only δ and σ, the API reports ensemble statistics from sampled fields, not a unique realization.

1 · Physics, parameters and architecture

Use the same n=25 lattice, 625 nodes and 1,200 possible edges. For each realization p=0.5+δU, U∼Uniform(−1,1); active edges have g=exp(σZ). The neural conditioning scalars include δ,p,σ; node inputs include coordinates, conductance and topology descriptors, and shortest resistance distances to the two boundaries. Given the full g field, δ,p,σ are redundant distribution descriptors, not additional forces in Kirchhoff’s law.

E(h;g) = Σₑ gₑ(hᵤ−hᵥ)², h_left=1, h_right=0
∂E/∂hᵢ = 2 Σⱼgᵢⱼ(hᵢ−hⱼ) = 0
G_exact = min_h E(h;g), G_est = E(h_θ;g) ≥ G_exact

The inequality holds for admissible fixed-boundary heads in exact arithmetic; it does not certify a tight error bound. Away from equilibrium, E(hθ) and the inlet flux from hθ need not agree, so both are reported separately.

A discrete, parametric PINN

  1. Connected components impose the exact head on one-boundary clusters and identify zero-flow networks. Floating clusters carry zero flow and have undefined absolute head.
  2. Dijkstra distances use resistances 1/g. Initialize h₀=d_right/(d_left+d_right) on spanning components. Uniform conductance scaling is canonicalized by the active-link median.
  3. A 21→32→32→1 node encoder predicts a bounded initial correction. A 6→16→2 parametric MLP predicts graph-level α,β. There are 1,939 trainable parameters.
  4. Apply a fixed number K of learned Kirchhoff-residual message-passing layers; clamp final heads to [0,1], which cannot increase graph energy.
Pᵢⱼ = gᵢⱼ / Σⱼgᵢⱼ
hᵏ⁺¹ = hᵏ − α(hᵏ−Phᵏ) + β(hᵏ−hᵏ⁻¹), on free nodes
β = 0.999 sigmoid(b), α = (1+β) 0.999 sigmoid(a)

This is a physics-informed unrolled graph network related to variational PINN/Deep Ritz ideas [1,2]. It deliberately contains repeated graph operations. It is neither a continuum coordinate-derivative PINN nor a claim that all computation disappears after training. For arbitrary boundary heads, h=h_R+(h_L−h_R)h_unit and Q_est=G_est(h_L−h_R); scaling all g by c scales G by c exactly.

2 · One-time training and model selection

Train on 4,096 spanning networks, retained from 8,155 independent generated fields. Nonspanning cases need no optimization because their response is fixed structurally. Half of δ and σ draws use scenario values {0,0.1,0.25} and {0,1,2}, respectively; the other half use Uniform(0,0.25) and Uniform(0,2). A single global p is then sampled per network.

Loss(θ) = mean log[E(hθ;g) / E(h₀;g)]
+ 0.01 mean [r²], r=hθ−Phθ on free nodes and zero elsewhere

The logarithm is monotone; each connected network’s energy minimum is the Kirchhoff solution. Training uses no reference head or conductance labels. Sparse reference solutions are generated only for 512 independent validation networks and for later paired tests. Adam uses initial learning rate 0.0015, weight decay 10⁻⁷ and gradient clipping 1. Batch size 32; 16 epochs with depth curriculum 32→64→128→256. Training uses float32; evaluation uses float64, on CPU with two PyTorch threads.

Training-loop time was 297.4 s; total offline setup, validation and depth selection took 334.7 s. Epoch 15 was selected. Fast mode uses K=256; accurate mode uses K=2048. Larger depth reuses the same learned weights; it is additional fixed message passing, not additional training.

Unmet validation target. The desired validation 99th-percentile G error below 0.1% was not met within the tested depth cap 2048 (observed 0.3707%). The most accurate tested depth was retained, and the failure is not hidden as a guarantee. No settings were tuned to improve the subsequent test results.

The fastest measured PINN setting is 4.35× the sparse G-only latency; no positive break-even is observed. Reusing weights avoids retraining and a sparse solve, but does not imply a runtime advantage. The original sparse method is already inexpensive; this neural architecture’s many fixed graph layers and preprocessing dominate cost.

The high-accuracy mode gives a smaller approximation error at greater inference cost. A positive break-even requires per-input neural cost lower than sparse cost; the measured break-even formula is T_offline/(t_sparse−t_neural) only when that denominator is positive. No training cost is hidden inside the reference timing. Model loading is excluded from warm inference and should be added for cold one-shot use.

The trained domain is n=25, δ∈[0,0.25], p generated around 0.5, and σ∈[0,2]. The OOD tests use σ=3, fully connected p=1, and n=15 or 41. For other sizes, the same learned weights are reused with regenerated graph-index buffers; no retraining is done. This is exploratory transfer, not a claim of uniform size or parameter generalization.

At σ=3, accurate-mode mean relative G error rises to 2.0779% and the maximum to 20.2555%. Strong contrast and weakly anchored clusters can converge slowly at fixed depth. The dense fully connected case can be easier despite lying outside the training distribution. Small G errors do not certify all heads or fluxes.

Exact boundaries and zero-flow routing are engineered physical constraints, not learned accomplishments. Component analysis and Dijkstra remain required per field. No corrected sparse solve is applied after the model. This architecture does not satisfy a stronger claim of instant scalar-only prediction for every possible random network. Model and sampling error must remain distinct.

8 · Use the trained model and reproduce the study

All new artifacts are separated under parametric_pinn/; the original solver, data and reports remain available. The repository contains trained and untrained checkpoints, training histories, complete paired prediction CSVs, sensitivity outputs, timing records, physical diagnostics, spatial examples, an executed notebook, report-generating scripts and editable presentation.

python parametric_pinn/scripts/predict.py --delta .25 --sigma 1 --p .6 --seed 42
python parametric_pinn/scripts/predict.py --delta .25 --sigma 1 --draws 1000
python parametric_pinn/scripts/predict.py --conductances field.npy --p .6 --sigma 1
make -C parametric_pinn all

The default CLI never calls the reference solver. Use --compare-reference explicitly for a check; --save-heads exports heads. Physical boundary heads and uniform conductance scale are supported. A .npy field has 1,200 entries, horizontal-then-vertical, row-major, as in the direct solver. API batch prediction reuses one loaded checkpoint. Different seeds can produce different results with the same δ,p,σ; with only distribution parameters, use multiple draws.

Verification and integrity

The 24 original tests plus 12 new PINN tests cover analytic grids, variational bounds, energy gradients, exact boundaries, zero flow, scale equivariance, batch equivalence, no-label training generation, and proof by monkeypatching that prediction does not call the sparse solver. A separate audit rechecks statistics, the zero-flow rule, field-energy consistency, checkpoint identity and the executed notebook. File checksums are in the root inventory.

Scientific conclusion

The study demonstrates a reusable physics-informed parametric graph map with accurate in-domain effective conductance for most cases. The direct solver gives stronger numerical precision and better measured CPU cost for this small lattice. Future work could remove dangling components analytically, learn multilevel preconditioners, optimize batched kernels or train neural operators for larger 3D fracture networks. Such changes require new validation and fair cost accounting, rather than assuming that a PINN is faster or uniformly accurate.
